## Xelu controller prompts

`Assets/ControllerArt/XboxSeriesController.svg` is an extracted and viewBox-
trimmed copy of the Xbox Series controller diagram from `Vector Source.svg` in
[haaldor/Xelu_prompts_SVG](https://github.com/haaldor/Xelu_prompts_SVG), commit
`9b8c47f76882dc79f9c30e8bc6e10b337baf575e`.

Original artwork: Nicolae “Xelu” Berbece. SVG extraction: Haaldor. The repository
and original prompt pack publish the artwork under the
[CC0 1.0 Universal Public Domain Dedication](https://creativecommons.org/publicdomain/zero/1.0/).

JoyCoding uses this diagram for standard Xbox Series controllers. Controller
input handling, hit locations, and live highlighting are JoyCoding code.
